# Most KIR/KPR Studio ↔ ProJest

## Ločitev nalog
| Program | Vloga |
|---------|--------|
| **ProJest Studio** | Vasco uvoz (IF*/kp*), konte, stranke (Minimax API + AJPES), XML→KirKpr |

## Vasco (samo ProJest)
Gumb **Uvozi Vasco** / Ctrl+O: mapa ali datoteke IF* (IR) + kp* (PR).
IR skupine: listina 3… = Darila, 2… = Fitnes.
PR obdobje: Datum prejema listine.

## Stranke (ProJest)
1. Minimax API → SQLite  
2. Manjkajoče → AJPES
